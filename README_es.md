# Creador de Stickers AI 🎨

> Selfie a packs de stickers. 3 estilos, 20+ packs temáticos. Paga con Telegram Stars. Invita amigos y obtén créditos gratis.

**[Abrir en Telegram](https://t.me/StickerAIMaker_Bot)** y envía /start para comenzar.
