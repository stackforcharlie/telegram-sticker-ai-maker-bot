# Criador de Stickers AI 🎨

> Selfie em pacotes de stickers. 3 estilos, 20+ pacotes temáticos. Pague com Telegram Stars. Convide amigos e ganhe créditos grátis.

Criador de Stickers AI é um bot do Telegram que transforma suas fotos em pacotes de stickers únicos. Estilos: **Kawaii**, **Cyber Neon**, **Brinquedo 3D**; pacotes: Escritório, Memes, Cripto, Academia, Gamer, Viagens. Pagamento via Telegram Stars; convide amigos para créditos grátis.
