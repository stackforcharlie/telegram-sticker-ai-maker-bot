# Мастер Стикеров AI 🎨

> Селфи в стикерпаки. 3 стиля, 20+ тематических паков. Оплата Telegram Stars. Приглашай друзей — бесплатные кредиты.

Мастер Стикеров AI — бот в Telegram, который превращает твои фото в уникальные стикерпаки. Стили: **Каваи**, **Кибер Неон**, **3D Игрушка**; паки: Офис, Мемы, Крипто, Спортзал, Геймер, Путешествия и др. Оплата через Telegram Stars; приглашай друзей для бесплатных кредитов.

**[Открыть в Telegram](https://t.me/StickerAIMakerBot)** и отправь /start.
